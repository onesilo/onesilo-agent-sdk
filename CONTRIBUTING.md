# Contributing

Issues and pull requests are welcome. By contributing you agree that your
contributions are licensed under the Apache License 2.0.

- `npm install` then `npm run lint` and `npm test` before pushing.
- Branches follow `<type>/<name>/<topic>` (feature, bugfix, chore, docs).
- The SDK tracks the MemoryStore specification in
  [silo-spec](https://github.com/onesilo/silo-spec); interface changes are
  additive-only and start as spec proposals there.
